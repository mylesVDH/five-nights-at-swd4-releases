> [!CAUTION]
> ## 🍎 MAC – STEP-BY-STEP GUIDE
>
> **The Mac version is EXPERIMENTAL.** It's built and checked automatically, but nobody has played it on a real
> Mac yet. If something looks or works wrong, please tell us!
>
> ### ✅ Before you start: does your Mac fit?
> - It needs a Mac with an **Apple chip (M1, M2, M3, M4 ...)**. Older Macs with an Intel chip can't run it.
> - Check it:  menu  → **About This Mac** → next to **Chip** it should say **Apple M...**
>
> ### 1. Download and unpack
> 1. Click the black **MAC** button at the top (or in **Releases → Latest → Assets**, click
>    **`Five.Nights.at.SWD4s-mac.zip`**).
> 2. Open your **Downloads** folder. Safari usually unpacks the zip by itself; if you only see the `.zip`,
>    **double-click** it. Now you have **Five Nights at SWD4's** (the app).
> 3. **Drag the app into your Applications folder** (in Finder, left side: **Applications**).
>    *(This is important – updates only work when the game is in Applications.)*
>
> ### 2. The first start (only once!)
> The Mac blocks apps that aren't from the App Store or a paid Apple developer. You allow this game once:
>
> 1. **Double-click** the game in Applications. A message appears: *"Five Nights at SWD4's" Not Opened –
>    Apple could not verify...*. Click **Done** (⚠️ **not** *Move to Trash*).
> 2. Open **System Settings** ( menu → System Settings) → **Privacy & Security** (left side).
> 3. Scroll **all the way down** to **Security**. There it says *"Five Nights at SWD4's" was blocked...*.
>    Click **Open Anyway**.
> 4. Type your Mac password (or use Touch ID), then click **Open Anyway** once more.
> 5. The game starts. From now on it opens with a normal double-click.
>
> *Older Macs (macOS 14 Sonoma or older):* you can also **right-click** (or Control-click) the app →
> **Open** → **Open**.
>
> ### 3. Questions the Mac asks – click **Allow / OK**
> - *"... would like to access files in your Documents folder"* → **OK** (that's where your save goes).
> - *"Do you want the application to accept incoming network connections?"* → **Allow** (needed for co-op).
> - *"... would like to access the microphone"* → **OK** if you want co-op **voice chat** (only asked when you
>   use it).
>
> ### 4. Good to know
> - **Fullscreen:** **Cmd + Ctrl + F** (the F11 key is used by macOS itself).
> - **Updates** work on Mac too: the menu shows **UPDATE AVAILABLE** when a new version is out.
> - **Co-op** works between a Mac and a Windows PC (same version needed).
>
> ### 😵 It says *"is damaged and can't be opened"*?
> That's the Mac's download check being extra strict, not a broken game. Open **Terminal** (Applications →
> Utilities), paste this line and press Enter:
> ```
> xattr -dr com.apple.quarantine "/Applications/Five Nights at SWD4's.app"
> ```
> It removes the "downloaded from the internet" mark from **this one app only** (nothing else on your Mac
> changes). Then double-click the game again.

## 🔄 Updates

You only download the game **once**. From version 5.4 on (Windows) and 5.6 on (Mac), the game updates itself:
when a new version is out, the main menu shows **UPDATE AVAILABLE** – click it, then **UPDATE NOW**.
Your save (progress, cash, skins, achievements) stays as it is.
You can turn this off in **Settings → Check for updates**.

## 🤝 Co-op

1. One player clicks **Co-op → HOST** and gets a **4-digit ROOM CODE**.
2. The other clicks **Co-op → JOIN** and types that code (or clicks the game in the list).
   - **Not on the same Wi-Fi?** The host clicks **PLAY ONLINE** and sends the **ONLINE code** (like `AB12-C3D`)
     instead – the friend types that in JOIN.
3. **Voice chat** works by itself (Settings → VOICE: microphone, push to talk, volumes). Use headphones.

Both players need the **same version**. If they're different, the co-op screen tells you who has to update.
Windows and Mac players can play together.

*Voice chat on Windows not working?* Windows Settings → Privacy & security → **Microphone** → turn on
**"Let desktop apps access your microphone"**.
