> ## 📥 HOW TO DOWNLOAD – STEP BY STEP
>
> **The easy way:** click the big red **DOWNLOAD** button at the top of this page. Done – skip to **step 4**.
>
> **If the button doesn't work, do it by hand:**
>
> 1. On the **right side** of this page, find the box called **Releases**.
>    *(On a phone or a small window it's further down the page.)*
> 2. Click the version with the green **Latest** label (for example **Version 5.4**).
> 3. Scroll down to **Assets** (click ▸ **Assets** if it's folded) and click **`Five.Nights.at.SWD4s.exe`**.
>    ⚠️ **Don't** click *Source code (zip)* or *Source code (tar.gz)* – those are NOT the game.
> 4. Your browser might warn you that the file *"isn't commonly downloaded"* or that it *"could be harmful"*.
>    That's because the game is new and not signed – not because something is wrong with it:
>    - **Edge:** hover over the download → click **⋯** → **Keep** → **Show more** → **Keep anyway**.
>    - **Chrome:** in the downloads list click **⋮** or the warning → **Keep** / **Download anyway**.
>    - **Firefox:** click the download arrow → **Allow download**.
> 5. Make a new folder (for example **Documents\Five Nights at SWD4's**) and move the exe into it.
> 6. **Double-click** `Five.Nights.at.SWD4s.exe` to play. The first start takes a few seconds.

> [!WARNING]
> ## 🛡️ "WINDOWS PROTECTED YOUR PC"?
>
> The first time you start the game, Windows may show a **blue screen** saying *"Windows protected your PC"*.
>
> 1. Click **More info** (small text under the message).
> 2. Click the **Run anyway** button that appears.
>
> You only need to do this once.
>
> **No "Run anyway" button / "Smart App Control blocked an app"?** Then Windows on that PC doesn't allow
> new unsigned programs, and the game can't be played there. Please play on another PC – **don't** turn off
> your PC's security for a game.

## 🔄 Updates

You only download the game **once**. From version 5.4 on, the game updates itself:
when a new version is out, the main menu shows **UPDATE AVAILABLE** – click it, then **UPDATE NOW**.
Your save (progress, cash, skins, achievements) stays as it is.
You can turn this off in **Settings → Check for updates**.
