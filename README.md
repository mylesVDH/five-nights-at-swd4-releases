# Five Nights at SWD4's — downloads

This page only holds the game's releases (no code).

**Download:** open [the latest release](../../releases/latest) and download `Five.Nights.at.SWD4s.exe`.
Put it in any folder and double-click it.

**Updates:** from version 5.4 on, the game updates itself — the main menu shows **UPDATE AVAILABLE** when a new
version is out. Your save stays as it is. (Turn it off in Settings → Check for updates.)

**What changed:** every release lists its changes.
